# Inline Dice Symbols — GM Reference

Type any of these codes anywhere that supports rich text (ability descriptions, notes, etc.) and they'll render as the matching icon.

Both `[bracket]` and `:colon:` style work. Codes are case-insensitive.

---

## Result Symbols

| Code | Aliases |
|---|---|
| `[success]` | `:success:` |
| `[failure]` | `:failure:` |
| `[advantage]` | `:advantage:` |
| `[threat]` | `:threat:` |
| `[triumph]` | `:triumph:` |
| `[despair]` | `:despair:` |

---

### Difficulty shortcuts

| Code | Equivalent |
|---|---|
| `:easy:` | `[difficulty]` |
| `:average:` | `[difficulty:2]` |
| `:hard:` | `[difficulty:3]` |
| `:daunting:` | `[difficulty:4]` |
| `:formidable:` | `[difficulty:5]` |

---

## Repeating a Symbol

Add `:N` after any code to repeat it N times:

```
[success:3]       → three success symbols
[difficulty:2]    → two difficulty dice
[threat:4]        → four threat symbols
```
